Transello - Translate with your favorite AI

A free Chrome extension for fast translation of text, selections and whole pages. Translation runs locally with Chrome's built-in translator, or with the AI you choose (OpenAI, Claude, DeepSeek, OpenRouter) using your own key. No account, no Transello server, no analytics.

  • Toolbar icon → paste → instant translation.
  • Select text → right-click → Translate in Transello.
  • Select a word → Alt+Shift+Y (Mac: Ctrl+Shift+Y) → mini popup.
  • Right-click a page → Translate page with Transello → “Show original” anytime.

Requires desktop Chrome 138+. Feedback: GitHub · Privacy policy
